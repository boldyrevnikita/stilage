# Описание формата сообщений для ML-сервиса
Примечание: все координаты и размеры задаются в миллиметрах (мм).

## Входные данные ML-сервиса

Актуальный формат входных данных модели находится в структуре данных `ModelInput` в `src/network/input_schema.py`.

## Выходные данные ML-сервиса

Актуальный формат выходных данных модели находится в структуре данных `ModelOutput` в `src/network/output_schema.py`.

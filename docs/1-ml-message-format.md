# Описание формата входных данных
Сразу условимся, что:
1. Мы работаем с видом "сверху-вниз";
2. Основной системой измерения являются метры (может быть изменено по требованию заказчика).

## Входные данные ML-сервиса

Так как работа проводится с двухмерной проекцией, то:
1. Каждый многоугольник будет задаваться следующим образом -- `[(x1, y1), (x2, y2), ...]` или `[x1, y1, x2, y2, ...]`, или `[[x1, x2, x3, ...], [y1, y2, y3, ...]]` (как удобнее бэку);
2. Каждый стеллаж будет задаваться через длинну, ширину и высоту -- `(l, w, h)`;

Список данных:
1. Стены здания (склада).
    - Многоугольник, задающий стены здания;
    - Необходимое свободное расстояние от стен;
    - `id` многоугольника, начинающийся с `1`;
2. Список доступных зон для расстановки стеллажей.
    - Многоугольники, задающие данные зоны;
    - Высота каждой зоны;
    - `id` зон, начинающийся с `2`;
3. Список специальных зон, в которых запрещенно (или невозможно) ставить стелажи.
    - Многоугольники, задающие данные зоны;
    - Необходимое свободное расстояние от каждой зоны;
    - `id` зон, начинающийся с `3`;
4. Список типов стеллажей.
    - Длинна, ширина и высота каждого типа стеллажей (будем считать, что ширина является стыковочной стороной между стеллажами одного типа);
    - Абсолютное, относительное, максимальное и минимальное количетсво стеллажей каждого типа. Может быть задано как одно значение, так и несколько из них. Если задано несколько значений, то они учитываются в следующем порядке абсолютное -> минимальное -> максимальное -> относительное (данное поведение может быть изменено по требованию заказчика);
    - Необходимое свободное расстояние между стыкующимися стеллажами одного типа;
    - Необходимое свободное расстояние от лицевой стороны (высоты) стеллажа каждого типа;
    - Необходимое свободное расстояние от боковой стороны (ширины) стеллажа каждого типа;
    - `id` типов стеллажей, начинающийся с `4`;
5. Дополнительный список количественного соотношения между стеллажами различного типа.
    - Элемент данного списка состоит из трёх полей `(id1, id2, ratio)`. Где `id1` -- первый тип стеллажей, `id2` -- второй тип стеллажей, `ratio` -- желамое отношение кол-ва стеллажей первого типа ко второму;
6. Дополнительный список свободного пространства между различными объектами.
    - Элемент данного списка состоит из трёх полей `(id1, id2, distance)`.Где `id1` -- идентификатор первого объекта, `id2` -- идентификатор второго объекта, `distance` -- расстояние между этими объектами.
